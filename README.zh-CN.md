# Hanbo Ma · 马涵柏

我是曼彻斯特大学电气与电子工程系博士研究生，导师为 Zhongguo Li 和 Zhengtao Ding。研究方向为具身智能、分布式系统、大语言模型推理与优化。

我的研究关注 AI 与分布式计算中的调度和控制方法，重点考虑延迟、内存容量与异构资源约束。博士入学前，我于北京航空航天大学获得控制科学与工程硕士学位，于吉林大学获得自动化学士学位。
